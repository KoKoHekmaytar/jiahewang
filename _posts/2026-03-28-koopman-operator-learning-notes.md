## Short summary

These papers are the milestones of the *Koopman Model*:
1. On Dynamic Mode Decomposition: Theory and Applications(2014)
2. Dynamic mode decomposition with control(2014)
3. A Data–Driven Approximation of the Koopman Operator: Extending Dynamic Mode Decomposition(2015)
4. Generalizing Koopman Theory to allow for inputs and control(2016)

Then, for *K-MPC*:
1. Linear predictors for nonlinear dynamical systems: Koopman operator meets model predictive control（2018）
